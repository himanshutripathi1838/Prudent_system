# Prudent Systems — Insight Engine

Prudent Systems Pvt. Ltd. platform for Industry 4.0, Industrial IoT, Edge AI, Data Acquisition (DAQ), and Railway Electronics (GPS OMS, Digital Speedometer).

## Development

Requires Node.js (v18+) and npm.

```sh
npm install
npm run dev
```

## Built With

- TanStack Start
- React 19
- TypeScript
- Tailwind CSS v4
- Three.js / React Three Fiber
